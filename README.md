# Employee Management System (EMS)

A responsive **Employee Management System (EMS)** built using **React.js, JavaScript, and Tailwind CSS**.

The application provides separate dashboards for **administrators and employees**, allowing administrators to create and assign tasks while employees can manage and track their assigned tasks.

---

## 🚀 Features

- Admin and employee login
- Separate Admin and Employee dashboards
- Employee management
- Create and assign tasks
- View assigned tasks
- Accept tasks
- Mark tasks as completed
- Mark tasks as failed
- Track task status
- Role-based dashboard rendering
- Persistent data using browser `localStorage`
- Reusable React components
- Responsive user interface
